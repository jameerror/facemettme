# Face Swap Me TT Me

แอป Python พร้อม GUI ภาษาไทยผ่านเบราว์เซอร์ สำหรับสลับใบหน้าจากภาพอ้างอิงไปยังภาพหรือวิดีโอ ประมวลผลในเครื่องด้วย InsightFace / INSwapper และ ONNX Runtime

รองรับ Linux cloud ทั้ง CPU และ NVIDIA GPU พร้อม Docker และ HTTPS เปิดใช้งานได้ทันทีโดยไม่ต้องล็อกอินหรือใส่รหัสผ่าน: ดู [LINUX_CLOUD.md](LINUX_CLOUD.md)

## เริ่มใช้งานบน Windows

ติดตั้ง Python 3.12 จาก https://www.python.org/downloads/ พร้อมเลือก Add Python to PATH แล้วเปิด PowerShell ในโฟลเดอร์โปรเจกต์

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

สำหรับ NVIDIA GPU:

```powershell
powershell -ExecutionPolicy Bypass -File .\install.ps1 -Gpu
```

ดับเบิลคลิก `start.bat` เบราว์เซอร์จะเปิด http://127.0.0.1:7860 โดยอัตโนมัติ ปิดหน้าต่างที่รันแอปเพื่อหยุดเซิร์ฟเวอร์

หากติดตั้งไลบรารีและโมเดลไว้แล้ว ให้เรียก `start.bat` ได้ทันที

## ติดตั้งด้วยตัวเอง / Linux

```sh
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python setup_models.py
python app.py
```

ตัวเลือก `python app.py --port 7861 --no-browser` สำหรับเปลี่ยนพอร์ตหรือไม่เปิดเบราว์เซอร์

## โมเดล

`setup_models.py` ดาวน์โหลดจากแหล่งทางการของ InsightFace และตรวจว่าโมเดลโหลดได้จริง เก็บไฟล์ในโปรเจกต์นี้:

```text
models/
  inswapper_128.onnx
  models/buffalo_l/*.onnx
```

หากลิงก์ดาวน์โหลด INSwapper ไม่พร้อมใช้งาน ให้ขอไฟล์ที่มีสิทธิ์ใช้จากผู้พัฒนา แล้วติดตั้ง:

```sh
python setup_models.py --swap-file "C:/path/to/inswapper_128.onnx"
```

ไม่รวม weights ในซอร์สนี้ โค้ด InsightFace และ pretrained weights มีสิทธิ์การใช้งานแยกกัน โดย weights ที่ผู้พัฒนาแจกใช้เพื่อการวิจัยที่ไม่ใช่เชิงพาณิชย์ ตรวจสิทธิ์หรือขอ license จากเจ้าของโมเดลหากต้องใช้เชิงพาณิชย์: https://github.com/deepinsight/insightface/tree/master/python-package

## วิธีใช้

1. เลือกภาพอ้างอิงที่มีใบหน้าชัดเจนหนึ่งคน JPG, PNG, WEBP หรือ BMP
2. เลือกภาพเป้าหมาย หรือวิดีโอ MP4, MOV, MKV, AVI, WEBM ขนาดไฟล์เป้าหมายสูงสุด 5 GB (5120 MiB) พร้อมรูปอ้างอิงแยกได้อีก 50 MB
3. เลือก Auto, CPU หรือ NVIDIA GPU (CUDA)
4. สำหรับวิดีโอ เลือกเวลาโดยกรอกวินาทีหรือเลื่อนแถบ แล้วกด **โหลดเฟรมและค้นหาใบหน้า** วิดีโอจะอัปโหลดครั้งเดียว ใช้เลือกเฟรมต่อและประมวลผลทั้งคลิปได้
5. คลิกรูปใบหน้าคนที่ต้องการเปลี่ยน เลือกได้หลายคนจากเฟรมนี้ หากคนที่ต้องการไม่อยู่ในเฟรมแรก ให้เลือกช่วงที่เห็นหน้าคนนั้นชัดเจน หรือเลือก **ทุกใบหน้าในทุกเฟรม**
6. กด **ดูตัวอย่างหลังสลับหน้า** เพื่อเทียบเฟรมก่อนและหลัง จากนั้นกดเริ่มงาน ดูความคืบหน้า แล้วดาวน์โหลด PNG หรือ MP4 สำหรับภาพนิ่งเลือกคนหลักหรือทุกใบหน้าแล้วเริ่มงานได้เลย

ภาพคนหลักใช้ใบหน้าที่ใหญ่ที่สุด วิดีโอจับคู่ embedding ของคนที่เลือกจากเฟรมตัวอย่างกับแต่ละเฟรมตลอดคลิป เมื่อคนที่เลือกไม่อยู่หรือคะแนนต่ำจะข้ามคนนั้น เมื่อมีคนคล้ายกันหรือหน้าถูกบัง อาจจับคู่ผิดหรือพลาดได้ โหมดทุกใบหน้าใช้หน้าอ้างอิงเดียวกันกับทุกคน รวมคนที่ปรากฏในเฟรมอื่นด้วย เปลี่ยนเวลาแล้วต้องโหลดเฟรมและเลือกคนใหม่ เวลาของเฟรมที่ดึงอาจต่างจากเวลาที่กรอกเล็กน้อยตามอัตราเฟรมของคลิป

วิดีโอถูกปรับเป็นอัตราเฟรมคงที่ก่อนประมวลผล และส่งออก H.264 / AAC พร้อมเสียงแทร็กแรกจากต้นฉบับเมื่อมีเสียง ใช้ FFmpeg ที่มากับ imageio-ffmpeg วิดีโอไม่เก็บ subtitles, metadata, HDR หรือเสียงหลายแทร็ก วิดีโอไม่มีเสียงก็ใช้ได้ เบราว์เซอร์อาจไม่แสดงตัวอย่าง MOV/MKV/AVI บาง codec แต่ยังส่งไปประมวลผลได้

## คุณภาพและความเร็ว

โมเดล INSwapper ทำงานกับใบหน้า 128×128 แล้วผสานกลับบนภาพต้นฉบับ ใช้ภาพอ้างอิงที่คมชัด แสงสม่ำเสมอ และมุมใกล้ภาพเป้าหมาย การตรวจจับ 1024 ช่วยใบหน้าเล็กแต่ไม่ได้เพิ่มรายละเอียดของโมเดลสลับใบหน้า ไม่มีการรับประกันความเหมือน 100% หรือภาพระดับ 4K บริเวณใบหน้า หน้าด้านข้างจัด การเคลื่อนไหวเร็ว แว่น หรือสิ่งบดบังอาจมีรอยต่อและความสั่นไหว CPU ใช้ได้ทั้งภาพและวิดีโอแต่ช้ากว่า GPU

GPU รองรับ NVIDIA CUDA ระบบแสดง provider ที่โหลดจริง หากโหมด Auto ใช้ GPU ไม่ได้จะกลับไปใช้ CPU หากเลือก GPU โดยตรงจะรายงานข้อผิดพลาดแทน โหลด CUDA/cuDNN DLL จาก runtime extras ก่อนเปิด ONNX session GPU อาจต้องติดตั้ง Visual C++ Runtime และไดรเวอร์ NVIDIA ที่เข้ากันได้ ดู https://onnxruntime.ai/docs/execution-providers/CUDA-ExecutionProvider.html

## ไฟล์และข้อมูล

เซิร์ฟเวอร์เปิดเฉพาะ loopback ของเครื่องนี้ งานทำทีละงาน ต้นฉบับที่อัปโหลดและไฟล์ชั่วคราวจะถูกลบหลังประมวลผล ผลลัพธ์ค้างอยู่ใน `data/<job-id>/` จนกดลบ วิดีโอและเฟรมตัวอย่างพักใน `data/editor/` จนเริ่มงานแล้วงานสิ้นสุด หรือกด **ล้างวิดีโอที่อัปโหลด** การปิดหน้าเว็บหรือแอปก่อนเริ่มงานอาจเหลือไฟล์เหล่านี้ งานและตัวเลือกบุคคลในหน่วยความจำหายเมื่อปิดแอป แต่ไฟล์ผลลัพธ์ยังอยู่ เปิดโฟลเดอร์ `data` เพื่อนำผลลัพธ์ออกหรือลบไฟล์ที่ไม่ต้องการได้

ในโหมด local ภาพและวิดีโอไม่ถูกส่งไปบริการ AI ภายนอก มีการเชื่อมต่ออินเทอร์เน็ตตอนติดตั้งไลบรารีและดาวน์โหลดโมเดลเท่านั้น ในโหมด cloud ไฟล์จะถูกส่งไปยังเซิร์ฟเวอร์ที่คุณติดตั้งเพื่อประมวลผล ดูรายละเอียดใน LINUX_CLOUD.md
